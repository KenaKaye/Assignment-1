# Data Directory

Place the raw Amharic corpus text file `GPAC.txt` in this folder:

* **Path:** `data/GPAC.txt`
* **Download link:** [Google Drive](https://drive.google.com/file/d/1jEOAORylTBAiNKes_JerD6gFF7cnLFyr/view?usp=sharing)

Saved deterministic splits (`split_indices_seed42.json`) and test sets (`q3_extrinsic_test_500.json`) are committed here for reproducible evaluation across all environments.
